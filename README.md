# AI-бот для ВКонтакте
Асинхронный AI-бот для сообществ ВКонтакте на базе LLM через [OpenRouter](https://openrouter.ai). Модель по умолчанию - `deepseek/deepseek-v4-flash-0731`.

## Возможности
- Многодиалоговый режим: создание, переименование, удаление и переключение диалогов.
- Переключение режимов общения (ролей): обычный помощник, программист, преподаватель, бизнес-консультант, дружелюбный собеседник.
- Краткосрочная память: бот помнит последние N сообщений каждого диалога.
- Долгосрочные факты: бот периодически извлекает и запоминает факты о пользователе (имя, интересы, предпочтения) и учитывает их в ответах.
- Хранение состояния в JSON-файлах (папка `users/`), без внешних баз данных.
- Интерактивные кнопки ВКонтакте, индикатор "печатает", обработка ошибок API.

## Требования
- Python 3.10+
- Токен сообщества ВКонтакте с правами `messages`
- API-ключ OpenRouter

## Установка и запуск
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Создайте файл `.env` на основе `.env.example`:
```
VK_TOKEN=токен_сообщества
VK_GROUP_ID=id_сообщества
OPENROUTER_API_KEY=ваш_ключ_openrouter
DEEPSEEK_MODEL=deepseek/deepseek-v4-flash-0731
```

Запуск:
```bash
python main.py
```

## Настройка сообщества ВКонтакте
1. Создайте сообщество и откройте "Управление" → "Работа с API".
2. Включите **Long Poll API** и нужные типы событий (входящие сообщения).
3. Во вкладке "Ключи доступа" создайте ключ с правом `messages`.
4. В разделе "Сообщения" включите сообщения сообщества и настройки для бота.

## Структура проекта
```
config/    - настройки из .env
models/    - сущности: пользователь, диалог, сообщение, режимы
storage/   - JSON-хранилище (users/)
services/  - AI-слой, менеджер диалогов, память, извлечение фактов
keyboards/ - клавиатуры ВКонтакте
bot/       - обработчики сообщений и кнопок, состояния
utils/     - логирование и вспомогательные функции
```
